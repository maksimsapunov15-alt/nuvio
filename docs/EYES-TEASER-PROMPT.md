Работаем над одним существующим проектом Next.js. Прочитай AGENTS.md и соответствующие разделы документации установленной версии Next.js в node_modules/next/dist/docs до изменения кода. Сначала проверь текущий git diff: другой агент мог уже выполнить часть работы. Сохраняй чужие изменения. Не редактируйте одни файлы одновременно: Codex реализует страницу, затем Claude проверяет результат и вносит точечные исправления.

## Задача

Временно превратить главную страницу в минималистичный интерактивный тизер. Сохранить прежний сайт в исходниках, но убрать с экрана его секции, меню, логотип, навигацию по главам, индикатор прокрутки, формы и футер. Не создавать публичный маршрут к старой версии.

При каждом открытии страницы на ЧЁРНОМ фоне сначала показывать по центру только вопрос «Хочешь узнать что это?». Через 2,8 секунды вопрос плавно исчезает, затем появляются глаза — это исходный сценарий, который пользователь просит сохранить. ТОЛЬКО дата «29.09.26» (29 сентября 2026 года) появляется под глазами после нажатия на любой глаз и остаётся видимой. Вопрос повторно по клику не показывать. Клик сохраняет тряску; глаза остаются на месте и продолжают следить за курсором. При обновлении страницы дата снова скрыта. Чёрный фон не менять.

Обновление по отзыву пользователя: прежняя картинка с инверсией отклонена. Глаза теперь должны выглядеть как спрайты хоррор-игр 90-х: чёткая пиксельная сетка, ограниченная серая палитра, светлые белки и тёмные зрачки, без бровей и ресниц. Сейчас это SVG-спрайты на сетке 256 × 96 с отдельными движущимися радужками и неподвижными веками. Не возвращать CSS-инверсию и размытую картинку. Исходный PNG оставлен в проекте как архив.

Взгляд обоих глаз плавно следует за курсором по всему экрану; смещение ограничено формой глаз, контуры остаются на месте. При уходе курсора из окна взгляд возвращается в центр. Клик по любому глазу запускает короткую затухающую тряску пары глаз; повторный клик перезапускает эффект. Нажатие на пустое место тряску не вызывает. Анимация слежения и тряски не должны конфликтовать.

На телефоне глаза помещаются по ширине, тап запускает тряску, не блокируется системный масштаб. Поддержать клавиатуру (Tab, Enter, Space), видимый фокус и prefers-reduced-motion (спокойное появление, без слежения и тряски, с мягкой реакцией на нажатие). Без лишних надписей, кнопок, звука, скролла и новых зависимостей.

## Передача работы

Последнее уточнение пользователя: коридор и фоновые эффекты отклонены и удалены. Использовать только чистый чёрный фон, без дымки, зерна, лампы и CRT-полос.

Последнее визуальное уточнение: сделать глаза страшнее. Реализованы узкие наклонённые веки, грязно-серые белки, приглушённые красно-коричневые радужки, вертикальные чёрные зрачки и редкое моргание с небольшой задержкой между глазами. Моргание отключено при prefers-reduced-motion.

Codex: реализуй страницу, сохрани старую композицию, проверь сборку и линтер, сообщи изменённые файлы и ограничения проверки. Не публикуй сайт без запроса.

Claude: сначала проверь уже готовый результат, не начинай заново. Проверь реальный вид в браузере на компьютере и телефоне: последовательность текста и глаз, плавность взгляда в крайних положениях, неподвижность контуров, отсутствие швов на картинке, повторные клики, тап, клавиатуру, reduced motion, отсутствие элементов старого сайта и ошибок консоли. Исправляй только найденные проблемы, сохраняя одобренную иллюстрацию и сценарий. Затем повтори относящиеся к изменениям проверки и передай краткий отчёт.
